================================================================================
                        NAVIGATION METHODS
================================================================================

Method 1: Navigate (Add to Stack)
  navigation.navigate('Camera');
  
  When to use: Normal screen transitions where user can go back
  Example: Welcome → Camera, Home → ReadingResult

Method 2: Replace (Replace Current Screen)
  navigation.replace('Processing', {
    capturedImageUri: 'file://...',
    readingId: 'reading_123'
  });
  
  When to use: Prevent back navigation during critical flows
  Example: Camera → Processing, Processing → Results

Method 3: Go Back
  navigation.goBack();
  
  When to use: Return to previous screen
  Example: Camera back button
